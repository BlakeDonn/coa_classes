Concept C · Guided questions, reasoned answers

Tell us how you like to play.

Answer any of the five questions. Every spec is then sorted into plain-language buckets with the exact reasons shown — there is no hidden score and no "fun rating." Skip any question you don't care about.

How matching works: each answer is a simple visible rule against the profile data (for example "calm pace" means Pace 3 or less). A spec with no rule conflicts is a strong fit. One conflict: worth a look. Two or more: probably frustrating. Rules run on our profile values, which mix snapshot data, player reports, and inference — each reason shows its evidence tier.

About this concept

Decision flow

Answer up to five plain questions → read the reasoned buckets → open full profiles from the cards → pin favorites to the tray → compare pinned picks.

What it does best

Cold start for players with zero CoA vocabulary. It converts self-knowledge ("I hate being punished") directly into candidates, and every match shows its working.

Main tradeoff

The matching rules are our inference stacked on our inference-tagged profiles. Bad rules silently misroute people, so the visible-reasons design is load-bearing, not decorative. Browsing and serendipity are weaker than the atlas.

Still needs research

  • Do these five questions predict actual enjoyment?
  • Threshold tuning (is Pace 3 "calm"?).
  • User testing on whether reasons are read or ignored.
